# Art Gallery

A modern React-based art gallery application that showcases famous artworks from around the world. The application features a responsive design, search functionality, and detailed information about each artwork.

## Features

- Responsive design that works on all devices
- Search functionality to filter artworks by title, artist, or category
- Detailed information about each artwork including description and category
- Smooth animations and transitions
- Modern UI with card-based layout

## Technologies Used

- React
- Vite
- React Router
- Font Awesome
- CSS3

## Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
cd art-gallery-vite
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the application for production
- `npm run preview` - Preview the production build
- `npm run lint` - Run ESLint to check for code issues
